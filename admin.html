SLURM 외 사용자 프로세스

SLURM 작업이 아닌 일반 사용자 프로세스의 사용자별 합계입니다 (CPU 0.5코어 또는 메모리 2 GB 이상). CPU는 최근 30초 평균이고, 실행 기간은 최대 메모리 프로세스 기준입니다.

접속

지금 접속 중인 계정과 접속한 곳의 주소입니다. screen·tmux 창은 '서버 안'으로 묶어 표시합니다. root는 최근 24시간 직접 로그인도 표시합니다. su로 전환한 경우는 기록되지 않습니다.

좀비 프로세스

좀비 자체는 kill로 지워지지 않습니다. 부모 프로세스가 회수하거나 종료되어야 사라집니다.

서버 상태

실패한 systemd 유닛

서버별로 실패 상태인 유닛과 실패 시각입니다. 최근 24시간 안에 실패한 유닛은 주의로 표시합니다. 쓰지 않는 유닛은 제외 칸으로 뺐습니다.

/root 폴더

서버별 /root 아래 2단계까지의 이름·크기·수정 시각을 10분마다 모읍니다. 파일 내용은 읽지 않습니다. 최근 24시간 안에 생기거나 바뀌거나 사라진 항목을 표시합니다.
