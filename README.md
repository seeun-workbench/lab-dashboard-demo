# 서버 대시보드 정적 데모

연구실 서버 8대를 보는 웹 대시보드의 세 화면(개요, 디스크 상태, 관리)을 서버 없이 열리게 만든 데모입니다.
화면을 보여 주기 위한 것으로, 실제 연구실 서버의 값은 하나도 들어 있지 않습니다.

바로 보기: https://seeun-workbench.github.io/lab-dashboard-demo/

## 여는 방법

위 주소로 열거나, 저장소를 내려받아 `index.html`을 더블클릭하면 브라우저에서 열립니다 (웹 서버가 필요 없습니다).
위쪽 탭으로 `disk.html`(디스크 상태), `admin.html`(관리)로 오갑니다. 관리 화면에 비밀번호는 없습니다.

## 무엇이 가짜인가

`demo_data.js`의 값은 모두 지어낸 것입니다.

- 서버 이름: `server-01` ~ `server-08` (실제 호스트 이름 아님)
- 계정 이름: 도커 컨테이너 이름처럼 형용사-명사를 무작위로 붙인 것 (`brave-otter` 식)
- 작업 이름, 실행 명령, 컨테이너 이름과 이미지, 실패한 systemd 유닛, `/root` 목록
- 접속 주소: 문서용으로 예약된 IP 대역(192.0.2.x, 198.51.100.x, 203.0.113.x)
- 디스크 일련번호(`DEMO…`), 온도·섹터·RAID 상태, 기존 모니터링 결과, 24시간 추세
- 시각: 2026-11-03 14:30에 고정되어 있습니다. 페이지 안의 시계도 그 시각에 멈춰 있어
  "N분 전", 경과 시간, 갱신 배지가 데이터와 어긋나지 않습니다. 갱신(폴링)은 하지 않습니다.

정상·주의·위험이 고루 보이도록 꾸몄습니다: 응답 없는 서버(server-04), 점검 중(server-05),
신규 작업 중지(server-06), 마운트 빠짐(server-07), 보류 섹터가 있는 디스크와 제거 대상 디스크(server-03),
재구축 중인 RAID(server-06), 스왑·OOM·GPU Xid(server-03), root 접속(server-07) 등.
관리 화면의 '점검 중' 스위치는 켜고 끌 수 있지만 브라우저 메모리에만 반영되고 새로 고치면 돌아갑니다.
